# Library

Resolve a BibTeX citekey to the PDF at:

```text
~/Documents/Library/<citekey>.pdf
```

For example, resolve `ainsworthGitReBasinMerging2023` to
`~/Documents/Library/ainsworthGitReBasinMerging2023.pdf`.

Before reading the paper, verify that the exact path exists. If it does not,
report this immediately.
Treat the whole `~/Documents/Library` as read-only.
